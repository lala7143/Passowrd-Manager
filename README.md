# Passowrd-Manager
At its core, a password manager is a secure database. Instead of storing passwords in plain text (which is a massive security risk), it uses encryption to scramble the data.

Key features typically include:
1.Encryption/Decryption: Using a master key to lock and unlock the vault.
2.Secure Storage: Saving credentials to a local file or database.
3.Password Generation: A built-in tool to create high-entropy, random strings (e.g., kP9!z$L2m).
